# Agenda's koppelen met een link (alleen lezen)

Zo toon je ook je **Outlook-, Hotmail- of Microsoft 365-agenda**: de app heeft geen twee-richtingen-koppeling met Microsoft, maar wel deze link. Het werkt voor elke agenda met een **.ics-link**. Afspraken verschijnen in het dashboard, maar je kunt ze daar niet aanpassen. Ze worden elke 15 minuten bijgewerkt.

**Instellingen → Agenda's → tabblad "Andere agenda's (alleen lezen)"**: kies je dienst (Google, iPhone/iCloud, Outlook, Samsung of Anders), volg de korte stappen om de link te vinden, plak hem en klik op **Koppelen**.

| Dienst | Waar vind je de link? |
|---|---|
| Google | Google Agenda op de computer → instellingen van de agenda → "Geheim adres in iCal-indeling" |
| iPhone / iCloud | Agenda-app → agenda delen → "Openbare agenda" → link kopiëren (begint met `webcal://`) |
| Outlook | Outlook.com → Instellingen → Agenda → Gedeelde agenda's → "Een agenda publiceren" → ICS-link |
| Samsung | Samsung Agenda heeft geen eigen link: gebruik de link van het Google- of Outlook-account waar de afspraken in staan |
| Anders | Elke link die eindigt op `.ics` of begint met `webcal://` |

Tips:
- Is de agenda al twee kanten op gekoppeld (Google), dan zou hij dubbel verschijnen. Het dashboard waarschuwt je daarvoor.
- Je kunt maximaal 12 agenda-links toevoegen.
- Links staan in het dashboard-bestand op je computer. Behandel een "geheime" link als een wachtwoord.
